# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/Saad-tech1606/Portfolio.git
```

Move into the project

```bash
cd Portfolio
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build production

```bash
npm run build
```
